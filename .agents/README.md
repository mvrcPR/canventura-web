# Eines de treball del projecte

Les pautes compartides viuen a [AGENTS.md](../AGENTS.md) i els plans i el seu
històric a [plans/README.md](../plans/README.md).

La carpeta `skills/` està preparada per afegir-hi fluxos reutilitzables quan
calguin. Cada skill tindrà una carpeta pròpia amb un `SKILL.md`, i podrà incloure
scripts, referències o recursos de suport.

```text
.agents/
  README.md
  skills/
    <nom-de-la-skill>/
      SKILL.md
```

Encara no hi ha skills específiques del projecte. El fitxer `.gitkeep` permet
conservar la carpeta buida a Git.

Convencions contrastades amb la documentació oficial d'OpenAI sobre
[AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) i
[skills locals](https://learn.chatgpt.com/docs/build-skills).
