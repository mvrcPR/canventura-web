## Aplicació de la skill d'instruccions

1. **Propòsit:** conservar els fluxos útils i eliminar les dependències del
   negoci i de la infraestructura del projecte d'origen.
2. **Inventari:** llegir les pautes de Can Ventura, els scripts disponibles i
   les instruccions i referències de les skills importades.
3. **Responsabilitats:** deixar les regles de marca a `AGENTS.md`, les decisions
   i la història a `plans/`, i els procediments reutilitzables a les skills.
4. **Llenguatge:** adaptar els passatges específics sense substituir el nom de
   l'empresa per un altre. Conservar el contingut genèric i els recursos útils.
5. **Evidència:** comprovar manifests, metadades, enllaços, recursos i scripts;
   diferenciar aquestes comprovacions d'una avaluació de comportament d'agents.

## Adaptacions

- Retirades les dependències de skills específiques de producte i màrqueting
  que no formen part d'aquesta instal·lació.
- Els idiomes es determinen a partir del projecte i de l'abast encarregat,
  sense assumir dues llengües o rutes fixes.
- La terminologia prové del negoci i de les seves fonts, sense importar el
  glossari de producte de la web d'origen.
- SEO descobreix els propietaris reals de rutes, renderitzat, analítica i
  validació; no prescriu fitxers ni comandes inexistents.
- Les recomanacions de UI respecten les referències i les decisions explícites
  de l'usuari abans de consultar la base de dades.
- Actualitzades les metadades d'invocació afectades i preservades les llicències
  i els recursos reutilitzables.
- La procedència es registra a `.agents/skill-sources.json`.

## Criteris de finalització

- Cinc carpetes completes i accessibles a `.agents/skills/`.
- Manifests vàlids i prompts d'invocació alineats amb la skill corresponent.
- Referències locals accessibles i cap dependència d'una skill no instal·lada.
- Cap regla específica del negoci, rutes o comandes del projecte d'origen
  dins de les skills generalitzades.
- Base de dades de UI comprovada i consulta per Astro executada correctament.
- Índexs i registre de procedència actualitzats.
